# A Little Book of Us

A handmade birthday gift: a small hand-painted 3D garden to wander through, with memories, little notes and a birthday letter. A soft opening theme plays, and lighting the candle turns it into Happy Birthday. Devices without WebGL get a flat watercolour book with the same pages.

**<https://vannyz1013.github.io/a-little-book-of-us/>**

## Making it yours

All personal content lives in [`src/data/birthdayContent.ts`](src/data/birthdayContent.ts). Replace everything in `[square brackets]`. Until you do, the page shows a small "placeholder" tag beside that text.

Photos go in `public/images/memories/`. Then set `photo` and `photoAlt` on the memory. Resize them to about 1600px on the long edge first, so the site stays quick on phones.

> The site is public on GitHub Pages: anyone with the link can see the photos and letter, and the repository is public too. Only add what you and your friend are comfortable with.

## Running it

```sh
npm install
npm run dev       # local preview
npm run build     # type-check and production build
```

Every push to `main` deploys to GitHub Pages through `.github/workflows/deploy.yml`.

## The music

The music comes in two parts, handled by one controller (`src/components/MusicPlayer.ts`):

1. **Opening theme** — `public/audio/ambient-garden.mp3`, a soft original piece (string pad, felt piano, celesta) generated by `tools/song/make_ambient.py`. Browsers don't allow sound before the visitor interacts, so it fades in on the first tap, click or key press anywhere.
2. **Birthday song** — `public/audio/happy-birthday.mp3`, an original synthesised music-box performance of the traditional public-domain melody, generated by `tools/song/make_song.py`. Lighting the candle or opening the gift crossfades into it (about 2.6 seconds, equal-power). It happens once: after that the song keeps playing, through the surprise, its replays and every scene.

Neither file uses an existing recording. To use your own, replace a file at the same path. If the birthday song is missing, the letter still opens and shows a note instead of the controls.

Pause, Mute and Replay appear on every scene once music is playing. Replay restarts whichever theme is playing; it never switches between them.

To regenerate (the MP3 encoder is a one-off tool, installed without saving: `npm install --no-save @breezystack/lamejs`):

```sh
python tools/song/make_ambient.py ambient.wav
node tools/song/encode_mp3.mjs ambient.wav public/audio/ambient-garden.mp3 96
```

The flat (no-WebGL) book plays only the birthday song, when the letter opens.

## The illustrations

All the art is painted procedurally by the scripts in `tools/paint/` (Python with numpy and Pillow):

```sh
python tools/paint/run.py              # repaint everything
python tools/paint/run.py birthday     # or one group: cover | decorations | birthday
```
